# Demonstração do projeto

1. Execute `python src/main.py`.
2. Pressione ENTER quando for solicitado o usuário Oracle para usar o modo offline.
3. Digite `7` e pressione ENTER para importar `dados/exemplo_amostragens.json`.
4. O programa importa 12 amostragens e rejeita uma inválida (talhão acima de 10 caracteres).
5. Digite `2` para listar as amostragens.
6. Digite `5` para gerar o relatório; responda `s` para gerar um arquivo TXT em `saidas/`.
7. Digite `6` para exportar os registros e indicadores em JSON.
8. Digite `9` para consultar o histórico, e `0` para sair.

## Observação

Exemplo de execução apenas em modo offline. As opções 3, 4 e 8 exigem Oracle configurado e conectado.
